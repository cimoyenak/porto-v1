## 🚀 Running Locally

Clone repository:

```bash
git clone https://github.com/cimoyenak/porto-v1.git
```

Masuk ke folder:

```bash
cd porto-v1
```

Install dependencies:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Buka `http://localhost:3000`.

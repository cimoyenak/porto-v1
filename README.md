## 🚀 Running Locally

Clone repository ini:

```bash
git clone https://github.com/cimoyenak/porto-v1.git
```

Masuk ke folder project:

```bash
cd porto-v1
```

Install dependencies:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Buka:

```text
http://localhost:3000
```
